Epic MD Viewer

Support & Help

Epic MD Viewer is a fast, native Markdown viewer for macOS. It renders .md, .markdown, and .mdx files with GitHub Flavored Markdown — including tables, task lists, syntax highlighting, and Mermaid diagrams — and reloads instantly when a file changes on disk. One-time purchase on the Mac App Store, macOS 13 or later.

Need help or have a question? Open a support request and we'll get back to you. We typically reply within 1–2 business days.

Getting started

  • Open a file: drag a Markdown file onto the app window or the Dock icon, double-click a .md file in Finder, or use File → Open (⌘O).
  • Live reload: keep the file open in your editor — Epic MD Viewer re-renders automatically each time you save.
  • Outline: use the sidebar to jump between headings in long documents.
  • Appearance: switch between System, Light, and Dark themes from the View menu.
  • Recent files: reopen recent documents from File → Open Recent.

Frequently asked questions

Which file types are supported?

Epic MD Viewer opens .md, .markdown, .mdx, .mdown, .mkd, and .mdwn files.

Can I edit files in the app?

No. Epic MD Viewer is a read-only viewer — it never modifies your files. Edit in your favorite editor and watch the preview update live.

Does it support Mermaid diagrams and code highlighting?

Yes. Fenced code blocks are syntax-highlighted, and mermaid code blocks render as diagrams automatically.

My file isn't updating when I save it.

Live reload watches the file on disk. If updates stop, close and reopen the file. If the problem persists, email us with your macOS version and a sample file.

Does the app collect any data or require a network connection?

No. Epic MD Viewer works fully offline, makes no network requests, and collects no personal data. See the Privacy Policy for details.

How do I request a feature or report a bug?

Open a request with as much detail as you can — including your macOS version and steps to reproduce any issue.
