# Epic MD Viewer — Support

**Epic MD Viewer** is a fast, beautiful Markdown viewer for macOS, available on the [Mac App Store](#).

## Getting Help

If you've run into a bug or have a question, please [open an issue](https://github.com/nunosiii/epic-md-viewer-support/issues) and we'll get back to you as soon as possible.

## Frequently Asked Questions

**What file types does Epic MD Viewer support?**
Epic MD Viewer opens `.md`, `.markdown`, `.mdown`, `.mkd`, and `.mdwn` files.

**Does the app edit my files?**
No. Epic MD Viewer is a read-only viewer — it never modifies your files.

**Does the app collect any data?**
No. Epic MD Viewer does not collect, transmit, or store any personal data.
